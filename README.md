🛸 Nostromo Restaurante
"En el espacio, nadie puede oír tus ganas de comer." > Una experiencia gastronómica inmersiva inspirada en la mítica nave de Alien.

🌌 Sobre el Proyecto
Nostromo Restaurante es una landing page temática diseñada para un restaurante conceptual basado en la estética de ciencia ficción industrial de la película Alien (1979). El objetivo de este proyecto es combinar un diseño visual potente con una interfaz de usuario fluida, permitiendo a los comensales (o tripulantes) explorar el menú, conocer las instalaciones y realizar reservas.

🎯 Características Principales
🛰️ Diseño Atmosférico: Estética oscura y futurista que emula los terminales de la USCSS Nostromo.

📱 Totalmente Responsivo: Optimizado para dispositivos móviles, tablets y escritorio.

📜 Menú Interactivo: Navegación por secciones de platos, bebidas y especialidades intergalácticas.

🕹️ Animaciones Fluidas: Uso de transiciones modernas para mejorar la experiencia del usuario.

📍 Sección de Contacto: Formulario de reserva y ubicación del sector espacial.

🛠️ Tecnologías Utilizadas
Para la construcción de este centro de mando gastronómico, se utilizaron:

HTML5 – Estructura semántica.

CSS3 – Estilizado avanzado, Flexbox y Grid.

JavaScript – Interactividad y lógica del sitio.

GitHub Pages – Hosting y despliegue.
